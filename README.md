## 📂 How to Use Bgent for Your Projects

Bgent uses markdown files to keep your tasks and schedules organized. Here is a simple way to get started:

1. **Create a New Project**

   In Bgent, select "New Project."

2. **Add Tasks**

   Write tasks as markdown headings. For example:  
   ```
   ## Task 1: Analyze Sample Data  
   - Collect data files  
   - Run preprocessing scripts
   ```

3. **Organize with Kanban**

   Group tasks by status: To Do, In Progress, Done. This helps you track progress visually.

4. **Set Deadlines**

   Add dates to your tasks to keep track of when things need to be finished.

5. **Save Your Work**

   All your work is saved in simple markdown files. You can open, edit, and share these files easily.
